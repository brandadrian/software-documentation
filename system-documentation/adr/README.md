# Architecture Decision Records

Architecture Decision Records (ADRs) document significant decisions of the system: the context, the decision, and its consequences.

## Creating a new ADR

1. Copy [0001-decision-title.md](0001-decision-title.md) to `NNNN-short-title.md` with the next zero-padded number.
2. Fill in all sections with verified facts only.
3. Add a row to the index above.
4. When a decision is replaced, set the old ADR to `Deprecated` and link the new one.
